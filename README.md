# Looking Glass DualScreen

Play American McGee's Alice on AYN Thor with gameplay on the main screen and a live HUD on the bottom screen.

[Download the latest APK](https://github.com/crazylobstergod/LookingGlass-DualScreen/releases/latest)

## Install and play

1. Install **LookingGlass-DualScreen-v0.32.0.88-arm64.apk**.
2. Open **Looking Glass DualScreen** and select your Alice game folder.
3. Let the app import your files and prepare the second-screen artwork, then play normally.

Setup is only needed once. Both screens start automatically when you open the app.

## Features

- Textured minimap with adjustable zoom.
- Live sanity, will and inventory display.
- Tap an owned weapon on the bottom screen to equip it.
- One APK with on-device game-file import.

You must provide your own game files. No commercial game data is included. This is an unofficial modification of the Looking Glass Android port.

## Updates

Install future DualScreen updates over the existing app. Back up your saves before changing distributions; uninstalling erases app data.
